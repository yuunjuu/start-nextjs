## Installation

1. npm 설치

- 버전: v25.2.1

2. pnpm 설치

```
npm install -g pnpm
```

3. VSCode 설정(setting.json)

```
"editor.formatOnSave": true,
"editor.defaultFormatter": "esbenp.prettier-vscode",
"editor.codeActionsOnSave": ["source.fixAll"]
```

4. VSCode Extensions

- Microsoft - ESLint
- Prettier - Prettier

5. Browser Extensions

Chrome/Edge

- React Developer Tools

## Getting Started

1. 서버 실행

VSCode > Run And Debug 에서 실행할 설정을 선택 후, 서버를 실행한다.

터미널에서 실행 시 아래와 같이 실행한다.

```bash
pnpm dev
```
